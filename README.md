## 📌 Project Overview

This project analyzes the performance of two digital advertising platforms — **Facebook Ads** and **AdWords** — using daily campaign data from 2019.

The analysis compares key campaign metrics such as **ad views, clicks, conversions, conversion rate, advertising cost, and cost per conversion** to understand the effectiveness of each platform.

The project combines exploratory data analysis with statistical techniques to identify meaningful differences and generate actionable insights for marketing campaign optimization.

---

## 🚨 Business Problem

Marketing teams need to understand which advertising platforms are delivering stronger results in order to make informed decisions about campaign optimization and budget allocation.

This project evaluates **Facebook Ads and AdWords** to determine which platform demonstrates stronger performance based on clicks, conversions, conversion rates, and cost-related metrics.

The analysis also investigates whether the observed differences in campaign performance are statistically significant.

---

## 🎯 Business Objectives

The key objectives of this project are to:

* Compare Facebook Ads and AdWords campaign performance.
* Analyze clicks and conversions generated by each platform.
* Compare conversion rates between the two campaigns.
* Examine advertising costs and cost per conversion.
* Analyze the relationship between clicks and conversions.
* Perform hypothesis testing to evaluate differences in conversion performance.
* Apply linear regression to examine relationships between campaign variables.
* Identify monthly and weekday campaign performance patterns.
* Generate business recommendations based on the analytical findings.

## 📂 Dataset

The dataset contains **365 daily observations** covering the period from **January 1, 2019, to December 31, 2019**.

It includes campaign performance information for both **Facebook Ads** and **AdWords**.

### Key Metrics

| Metric              | Description                                      |
| ------------------- | ------------------------------------------------ |
| Date                | Date associated with each campaign record        |
| Ad Views            | Number of times an advertisement was viewed      |
| Ad Clicks           | Number of clicks received by an advertisement    |
| Ad Conversions      | Number of conversions generated                  |
| Cost per Ad         | Advertising cost associated with the campaign    |
| CTR                 | Ratio of clicks to ad views                      |

## 4️⃣ Hypothesis Testing

Statistical hypothesis testing was performed to determine whether the difference in conversion performance between Facebook Ads and AdWords was statistically significant.

### Hypotheses

**Null Hypothesis (H₀):**

There is no significant difference in conversion performance between Facebook Ads and AdWords.

**Alternative Hypothesis (H₁):**

There is a significant difference in conversion performance between Facebook Ads and AdWords.

### Significance Level

The analysis uses a significance level of:

**α = 0.05**

### Decision Rule

* **p-value < 0.05** → Reject H₀
* **p-value ≥ 0.05** → Fail to reject H₀
